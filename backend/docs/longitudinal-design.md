# 縦断型インタビュー

最初のセッションは、自己紹介のような自然な会話で仕事の全体像と人柄を知り、ラポールを形成します。役職や立場、経験年数、業務内容の概要、日頃の業務や責任の範囲、よく一緒に仕事をする関係者、本人が仕事で大事にしていることを、回答に合わせて一つずつ尋ねます。一日の流れも話題にできます。固定順の質問票にはせず、既に分かったことは聞き直しません。大事にしていることは気軽に尋ねますが、理由や形成背景、作業手順や判断の根拠は深掘りしません。話しづらい話題は追いません。

初回面談は7往復程度を目安とします。本人の回答が7回以上かつ抽出項目が5種類以上になれば終了し、情報が少なくても9回で終了します。全項目の充足は必須にしません。本人の終了希望と手動終了は回数によらず優先します。抽出項目と保存用の英語フィールド名は維持し、質問生成の方針は日本語で明示します。

2回目以降は「先ほどしていた業務」を入口にし、今回の具体的な経験から理由、価値観、形成背景へ進みます。

プロフィール、セッション要約、根拠メッセージID付きの記憶ノードと関係を SQLite に保存します。回答に関連する過去情報だけを選び、今回の状態や深さには加算しません。過去の理由や価値観を今回も当てはまると決めつけず、本人が訂正できる余地を残します。

実装は interview/profile_agent.py、interview/longitudinal.py、db/memory.py に分けています。セッション終了後の記憶抽出は FastAPI の background task で行います。
