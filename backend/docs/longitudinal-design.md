# 縦断型インタビュー

最初のセッションで担当、役割、経験、責任範囲、一日の流れ、関係者をプロフィールとして確認します。2回目以降は「先ほどしていた業務」を入口にし、今回の具体的な経験から理由、価値観、形成背景へ進みます。

プロフィール、セッション要約、根拠メッセージID付きの記憶ノードと関係を SQLite に保存します。回答に関連する過去情報だけを選び、今回の状態や深さには加算しません。過去の理由や価値観を今回も当てはまると決めつけず、本人が訂正できる余地を残します。

実装は interview/profile_agent.py、interview/longitudinal.py、db/memory.py に分けています。セッション終了後の記憶抽出は FastAPI の background task で行います。
