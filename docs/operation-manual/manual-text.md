# インタビューの操作方法

いつものお仕事の内容や工夫を、普段の言葉で教えてください。1日に何度でも、同じ画面からインタビューを始められます。

**基本はハンズフリー**：「ヘイウィスパー」で始めて、質問に声で答えます。

**答えの最後に「どうぞ」**：「どうぞ」または「オーバー」と言うと送信されます。

**文字入力もできます**：声を出せないときや、認識が気になるときに使えます。

## 1. 声でインタビューをはじめる

**「ヘイウィスパー」で開始**

案内されたIDでログインします。パスワードは空欄のままで大丈夫です。マイクを許可し、開始待ちの画面で「ヘイウィスパー」と呼びかけてください。

「インタビューを開始」ボタンでも始められます。ボタンで始めた場合は、「音声で回答する」を押すと音声モードになります。

## 2. 声で答えて、最後に「どうぞ」

**最後に「どうぞ」または「オーバー」**

質問の読み上げが終わり、上部が「Recording」（録音中）になったら話します。答えの最後に「どうぞ」または「オーバー」と言うと、自動で送信されます。

次の質問の後も、自動で録音が始まります。質問ごとに画面を押す必要はありません。「録音中（停止して送信）」ボタンでも送信できます。

## 3. 必要なときは、文字で答える

**声でも、文字でも切り替え自由**

音声の誤認識が気になるときや、声を出せないときは、入力欄を押して文字で回答できます。内容を確認してから「送信」を押してください。

入力欄を押すと音声モードが止まり、送信前の録音は取り消されます。音声に戻るときは「音声で回答する」を押します。

## 4. 保存を待って、そのまま次の回へ

**終わっても、同じ画面のままでOK**

質問が終わると自動で終了します。途中で終える場合は、画面上部の「インタビューを終了」を押します。

終了の挨拶の後、記録が終わって開始待ちに戻るまでお待ちください。次に話したいときは、同じ画面でまた「ヘイウィスパー」と呼びかければ、新しい回が始まります。

## 1日に何度でも、同じ画面から

インタビューが終わっても、この画面を開いておいてください。作業の途中や区切りなど、話したいタイミングで「ヘイウィスパー」と呼びかければ、2回目以降もハンズフリーで始められます。毎回ログインし直す必要はありません。

「ヘイウィスパー」→ 質問に答える → 保存を待つ → また呼びかける

呼びかけは、記録が完了した「開始待ち」の画面で使います。スマホをポケットに入れる場合も、サイトを開いた状態でご利用ください。画面ロック中や別アプリの使用中の動作は保証されません。音声で開始できないブラウザでは、開始ボタンをご利用ください。

## こんなときは？

### 音声の誤認識が気になるときは？

入力欄を押して文字で回答してください。送信前に内容を確認できるので、正確に伝えたい言葉や数値があるときにも使えます。




### 声を出せない場所・状況では？

音声を使わず、入力欄に回答を書いて「送信」を押せます。途中から文字入力へ切り替えても、同じインタビューを続けられます。




### 「どうぞ」が反応しない／Recordingにならないときは？

音声モードをいったん切り替えて、もう一度録音を始めてください。

1. テキストの入力欄を一度押します。
2. 「音声で回答する」を押します。
3. 上部が「Recording」になってから、もう一度回答し、最後に「どうぞ」または「オーバー」と言います。

切り替えると送信前の録音は取り消されます。送信だけがうまくいかない場合は、「録音中（停止して送信）」ボタンでも送れます。音声認識中・考え中は、処理が終わるまでお待ちください。

### 「ヘイウィスパー」で始まらないときは？

記録が終わって開始待ちに戻っているか、マイクが許可されているか、サイトの画面が開かれているかを確認してください。「インタビューを開始」ボタンでも始められます。


質問に答えている途中は、毎回「ヘイウィスパー」と呼びかける必要はありません。回答の最後の「どうぞ」または「オーバー」だけで次へ進めます。

困ったときは、画面下の「操作マニュアル」を押してください。確認中は録音・読み上げが一時停止します。会話や入力中の文章は残り、閉じると続きに戻れます。
