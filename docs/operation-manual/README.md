# 対象者向け操作マニュアル

配布用の [操作マニュアルPDF（A4・3ページ）](../../frontend/public/manual/interview-manual.pdf) を用意しています。画面上部まで含むスクリーンショットと、ハンズフリー・文字入力・繰り返しの実施・困ったときのQ&Aをまとめています。サイト内の「操作マニュアル」からも同じPDFを保存できます。

## 依頼に添える説明の例

いつものお仕事の進め方や工夫について、インタビューへのご協力をお願いします。

案内したURLを開き、お渡ししたIDでログインしてください。初めての方には操作方法が表示されます。基本はハンズフリーで、「ヘイウィスパー」と呼びかけると始まり、回答の最後に「どうぞ」または「オーバー」と言うと送信されます。声を出せないときや、音声の認識が気になるときは文字でも回答できます。

1日に何度でもご利用いただく想定です。終了後は、記録が終わるまで待ち、画面を開いたままにしてください。次に話したいときは同じ画面で「ヘイウィスパー」と呼びかければ、新しい回を始められます。途中で操作がわからなくなったら、画面下の「操作マニュアル」をご覧ください。

## 内容・画面

- [説明文だけを見る](manual-text.md)
- [サイト内で開いた画面](site-preview.png)
- [スマートフォン幅での画面](mobile-preview.png)

掲載したスクリーンショットは、実際のUIを操作説明用のサンプルデータで撮影しています。実在の対象者の会話は使用しません。

PDFは1ページ目に開始・音声回答、2ページ目に文字入力・終了、3ページ目に1日の繰り返しとQ&Aを掲載しています。画像は上部の状態表示から下部の操作欄までを切り取らずに載せ、サイト内では画像を押して拡大できます。「どうぞ」が反応しない／Recordingにならない場合は、入力欄を一度押してから「音声で回答する」を押し直す手順を載せています。

## 後から作業中のイラストを追加する

作成いただくイラストの配置先が決まったら、`frontend/public/manual/` に画像を置き、`frontend/src/manualContent.ts` の `repeat.image` を `/manual/ファイル名.png` のようなサイト内パスに設定します。`repeat.imageAlt` は画像の説明です。PNG・JPEG・WebP・SVGに対応します。

現在は画像パスを空にしてあり、未配置の画像や空の枠は表示しません。パスを設定して下記の生成コマンドを実行すると、サイト内の「1日に何度でも」の説明とPDFの同じ説明箇所の両方へ画像を組み込みます。画像追加後はPDFの改ページも確認してください。

## サイト内の動作

「設定・履歴」の横にある「操作マニュアル」から開きます。インタビューのコンポーネントを残したまま重ねて表示するので、会話や入力途中の文章を保持します。開いている間は録音・読み上げ・質問文の表示を一時停止し、閉じると再開します。録音は同じMediaRecorderをpause/resumeし、途中の音声を捨てたり、その場で送信したりしません。処理中のサーバー要求はそのまま完了させ、次の読み上げ・録音をマニュアルを閉じるまで待ちます。

初回の自動表示は、まだセッションがなく、マニュアルを未確認の対象者に対して行います。「確認しました」を押すと `manual_acknowledgements` にアカウントごとに保存し、別の端末でログインしても繰り返し自動表示しません。過去にインタビューを実施済みの対象者と管理者には自動表示せず、参照したいときに開けます。確認の保存に失敗した場合は再試行でき、確認前にインタビューを開始しません。

反映にはバックエンドを再起動し、新しいフロントエンドを読み込んでください。DBへの新テーブル追加は起動時に行います。PDF・画像はフロントエンドの静的ファイルとして配信します。

## 内容やスクリーンショットを更新する

本文は `frontend/src/manualContent.ts` が共通の編集元です。次のコマンドでサンプルAPIを使用したブラウザ撮影とPDFの生成を行います。既存のアカウントや会話は変更しません。

```bash
cd /home/mana/AudioInterview/frontend
npm install
PLAYWRIGHT_BROWSERS_PATH=/tmp/audiointerview-playwright npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/audiointerview-playwright npm run manual:generate
npm run build
```

PDF・画像は `frontend/public/manual/`、文面と確認用プレビューは `docs/operation-manual/` に保存します。生成コマンドでは、初回表示・録音の一時停止／再開・入力途中の文章の保持・同じ画面から呼びかけによる2回目の開始・再読み込み後の非表示もブラウザで確認します。
