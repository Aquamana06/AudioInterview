# Web UI

    npm install
    npm run dev

開発時は Vite が `/api` を `http://127.0.0.1:8000` の Python API に転送します。API を起動するには `../backend/README.md` を参照してください。

回答はテキスト・音声のどちらでも入力できます。

- テキスト: 入力欄に回答し、「送信」または Enter で送信します。Shift+Enter は改行、IME 変換中の Enter は確定に使えます。マイク権限は不要です。
- 音声: 「音声で回答する」を押すとマイク録音を開始します。「録音中（停止して送信）」を押すか、「オーバー」と話すと音声回答を送信します。
- 録音中・音声認識中に入力欄を選ぶとテキスト入力へ切り替わり、その音声回答は送信しません。

インタビューが自動終了した場合も「終了」を押した場合も、録音・読み上げを停止し、「インタビューの内容を記録しています」と表示します。バックエンドの記録処理が完了すると、自動でホームへ戻ります。記録中は次のインタビューを開始できず、ページを再読み込みしても完了待ちを再開します。要約生成に失敗した場合は、保存済みの発話抜粋を記録として保持してホームへ戻ります。履歴から記録済みのセッションを開いた場合は「ホームに戻る」を利用できます。

新しいインタビューの準備中も開始ボタンを無効にし、連打による重複作成を防ぎます。最初の質問の生成に失敗した場合、再試行では作成済みの同じセッションを使用します。

音声認識はバックエンドの `POST /api/speech/transcribe` で行います。ブラウザはマイク録音と音声の送信を担当し、WebGPU やモデルのダウンロードは不要です。「オーバー」による自動停止も、短い音声をAPIへ送って判定します。
