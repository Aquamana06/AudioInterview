# インタビューの操作方法

いつものお仕事のことを、普段の話し言葉で自由に教えてください。業務の区切りのよいタイミングで、実施してください。個人情報や秘匿用語もお話いただいて問題ありません。

## はじめに：ログインとマイクの許可

AndroidやパソコンではGoogle Chrome、iPhone・iPadではSafariの最新版をご利用ください。パソコンのMicrosoft Edgeでも、開始ボタンから利用できます。呼びかけでの開始はブラウザや端末によって使えない場合があります。そのときは「インタビューを開始」を押してください。

1. 案内されたURLをブラウザで開き、「AIインタビュー」のログイン画面を表示します。
2. お渡ししたIDを「ユーザーID」に入力します。パスワードを空欄のままにして、「ログイン」を押してください。
3. 初めてログインしたときは、この操作マニュアルが表示されます。読み終えたら「確認しました」を押します。
4. 「マイクの使用を許可しますか？」と聞かれたら「許可」を選び、マイクをオンにしてください。音声での開始や回答のために必要です。録音を始めるときに、もう一度聞かれた場合も許可してください。

もし「許可しない」を選んでしまったときは、ブラウザのこのサイトの設定で「マイク」を「許可」に変更してから、ページを開き直してください。端末側でブラウザのマイクがオフになっている場合は、そちらもオンにします。

## ハンズフリーで進める場合

### 1. 開始

**「ヘイウィスパー」と呼びかける**

開始待ちの画面に向かって「ヘイウィスパー」と呼びかけてください。音声モードでインタビューが始まり、質問が読み上げられます。

呼びかけで始めると、質問ごとに画面を押さずに回答を続けられます。呼びかけが使えない場合は、「画面を操作して進める場合」の手順で始めてください。

### 2. インタビューの進行

**声で答えて、最後に「どうぞ」**

質問の読み上げが終わり、左上が「Recording」になったら話し始めます。答え終わったら「どうぞ」または「オーバー」と言ってください。合図が認識されると録音が止まり、左上が「サーバーで音声認識中」に変わります。その後、回答が自動で送られます。

左上が「インタビュアーが考え中…」になったら、次の質問をお待ちください。次の質問の読み上げ後も自動で録音が始まります。「どうぞ」「オーバー」と言う代わりに、「録音中」の横にある「停止して送信」ボタンを押して回答を送ることもできます。

### 3. 終了

**終了の挨拶の後、記録が終わるのを待つ**

質問が終わると自動で終了し、終了の挨拶が読み上げられます。そのまま記録が完了し、開始待ちに戻るまでお待ちください。

次に話したいときは、同じ画面でまた「ヘイウィスパー」と呼びかければ、新しい回が始まります。

## 画面を操作して進める場合

### 1. 開始

**「インタビューを開始」を押す**

開始待ちの画面で「インタビューを開始」を押してください。画面に最初の質問が表示されます。

### 2. インタビューの進行

**回答は音声でも、テキストでもOK**

テキストで答えるときは、画面の質問を読み、入力欄に回答を書いて「送信」ボタンもしくはEnterを押します。」

テキストでは読み上げや録音はなく、「送信」を押すまで回答は送られません。送信の確認方法は、ハンズフリーの手順2と同じです。

### 3. 終了

**終了の挨拶の後、記録が終わるのを待つ**

質問が終わると自動で終了します。音声モードでは終了の挨拶が読み上げられ、テキストでは画面に表示されます。そのまま記録が完了し、開始待ちに戻るまでお待ちください。

次に回答したいときは、同じ画面でまた「インタビューを開始」を押すと、新しい回が始まります。

## 音声とテキストを途中で切り替える場合

### 1. 開始

**最初に使いたい方法で始める**

ハンズフリーで始めるときは「ヘイウィスパー」と呼びかけます。画面を操作して始めるときは「インタビューを開始」を押します。ボタンで始めた場合も、「音声で回答する」を押せば音声で回答できます。

開始後も、同じインタビューの途中で回答方法を切り替えられます。

### 2. インタビューの進行

**音声→テキストは入力欄、テキスト→音声は下のボタン**

音声からテキストに切り替えるときは、入力欄を押します。読み上げと録音が止まるので、回答を入力して「送信」を押してください。テキストから音声に切り替えるときは、下の「音声で回答する」を押します。

入力欄を押すと、送信前の録音は取り消されます。録音中に話した内容も送りたい場合は、切り替え後に入力し直してください。

### 3. 終了

**どちらの方法でも、記録が終わるのを待つ**

質問が終わると自動で終了します。音声モードでは終了の挨拶が読み上げられ、テキストでは画面に表示されます。そのまま記録が完了し、開始待ちに戻るまでお待ちください。

次の回も、「ヘイウィスパー」と呼びかけるか、「インタビューを開始」を押すと始められます。

## 同じ画面のまま、上記の各パターンの1~3のステップからなる1セッションのインタビューを20~30回を目安に実施してください

インタビューが終わっても、この画面を開いておいてください。作業の途中や区切りなど、話したいタイミングで「ヘイウィスパー」と呼びかければ、2回目以降もハンズフリーで始められます。毎回ログインし直す必要はありません。

「ヘイウィスパー」→ 質問に答える → 保存を待つ → また呼びかける

呼びかけは、記録が完了した「開始待ち」の画面で使います。スマホをポケットに入れる場合も、サイトを開いた状態でご利用ください。画面ロック中や別アプリの使用中の動作は保証されません。音声で開始できないブラウザでは、開始ボタンをご利用ください。

## こんなときは？

### マイクを許可するには？

ブラウザに「マイクの使用を許可しますか？」と聞かれたら「許可」を選んでください。拒否してしまった場合は、このサイトのマイク設定を「許可」に変更します。

1. Chrome・Edgeでは、アドレス欄の左側にあるサイト情報から、マイクの権限を確認します。
2. iPhone・iPadのSafariでは、ページメニューのWebサイト設定から「マイク」を「許可」にします。
3. 変更後はページを開き直し、「インタビューを開始」→「音声で回答する」を押します。

表示名は端末によって異なります。音声入力が使えない場合も、文字で回答できます。

### 音声の誤認識が気になるときは？

入力欄を押して文字で回答してください。送信前に内容を確認できるので、正確に伝えたい言葉や数値があるときにも使えます。




### 声を出せない場所・状況では？

音声を使わず、入力欄に回答を書いて「送信」を押せます。途中から文字入力へ切り替えても、同じインタビューを続けられます。




### 「どうぞ」が反応しない／Recordingにならないときは？

音声モードをいったん切り替えて、もう一度録音を始めてください。

1. テキストの入力欄を一度押します。
2. 「音声で回答する」を押します。
3. 上部が「Recording」になってから、もう一度回答し、最後に「どうぞ」または「オーバー」と言います。

切り替えると送信前の録音は取り消されます。送信だけがうまくいかない場合は、「録音中」の横にある「停止して送信」ボタンでも送れます。音声認識中・考え中は、処理が終わるまでお待ちください。

### 「ヘイウィスパー」で始まらないときは？

記録が終わって開始待ちに戻っているか、マイクが許可されているか、サイトの画面が開かれているかを確認してください。「インタビューを開始」ボタンでも始められます。


質問に答えている途中は、毎回「ヘイウィスパー」と呼びかける必要はありません。回答の最後の「どうぞ」または「オーバー」だけで次へ進めます。

### ログアウトはどこからできますか？

画面下の「設定・履歴」を開くと、「ログアウト」があります。インタビューが終わり、記録が完了して開始待ちに戻ってから押してください。


インタビュー中や記録中は、ここからログアウトできません。繰り返しインタビューを受ける間は、ログインしたままで大丈夫です。

### インタビューの途中でログアウトするとどうなりますか？

「設定・履歴」のログアウトはインタビュー中には押せません。パソコンのサイドバーなど別の操作でログアウトした場合、送信済みの回答は残りますが、入力途中の文字や送信前の録音は失われます。ログアウトだけでは、その回のインタビューは終了しません。


再ログイン後、「設定・履歴」の「セッション履歴」から該当する回を選ぶと、送信済みの会話から続けられます。音声で続けたい場合は「音声で回答する」を押し、未送信だった内容はもう一度お話しください。

### 都合が悪くなり、途中で終えたいときは？

通常は質問が終わると自動で終了しますが、急な用事などで続けられないときは、画面上部の「インタビューを終了」から、その回をいつでも途中で終了できます。


音声認識中や送信中など、ボタンを押せない間は処理が終わるまでお待ちください。送信前の録音や入力中の文章は回答に含まれません。終了の挨拶の後、記録が完了するまで待ってください。終了した回への回答の追加はできませんが、開始待ちに戻れば新しい回を始められます。

困ったときは、画面下の「操作マニュアル」を押してください。確認中は録音・読み上げが一時停止します。会話や入力中の文章は残り、閉じると続きに戻れます。
